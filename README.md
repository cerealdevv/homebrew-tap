# Cerealbox Tap

## How do I install these formulae?

`brew install cerealbox/tap/<formula>`

Or `brew tap cerealbox/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cerealbox/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
